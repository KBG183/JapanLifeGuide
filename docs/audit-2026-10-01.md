# 전체 검수 및 유사 서비스 비교

검수일: 2026-10-01

## 검수 범위

- `README.md`, `docs` 문서, `sql` 전체
- Java 소스, MyBatis 매퍼, 다국어 메시지
- JSP 화면, CSS, JavaScript, 테스트
- H2 미리보기 프로필의 자동 테스트와 빌드된 WAR HTTP 응답

Oracle 데이터베이스에는 접속하지 않았고 SQL을 실행하지 않았다. 따라서 이 문서의 DB 구조 평가는 프로젝트 SQL과 사용자가 제공한 실행 결과를 기준으로 한다.

## 확인하고 수정한 사항

- 커뮤니티 이미지의 개수·용량·형식뿐 아니라 실제 파일 헤더를 검사하고 안전한 저장 파일명을 사용하도록 수정했다.
- 존재하지 않거나 비공개인 커뮤니티 게시글에 댓글·좋아요·신고를 할 수 없도록 수정했다.
- 커뮤니티 제목·본문·댓글과 관리자 화면의 사용자 입력 출력에 HTML 이스케이프를 적용했다.
- 서버에만 있던 게시글·댓글 삭제와 신고 기능을 상세 화면에서 사용할 수 있도록 연결했다.
- 본인 콘텐츠 신고와 동일 대상의 중복 미처리 신고를 차단했다.
- 좋아요는 페이지를 새로 고치지 않고 처리하며 버튼 문구는 계속 같은 문구를 사용하고 선택 상태만 색상과 `aria-pressed`로 표시한다.
- 절차 목록의 키워드 검색 입력란을 복구했다.
- 언어를 바꿔도 검색어·상황·단계·페이지 쿼리가 유지되도록 수정했다.
- 번역되지 않은 개별 서류 링크 키가 `???키???` 형태로 노출되지 않도록 수정했다.
- 관리자 하위 화면의 레이아웃과 다국어 표 머리글을 통일하고 자기 계정 권한·상태 변경 버튼을 막았다.
- 관리자 입력값 길이와 공식 URL의 HTTPS 및 공공기관 도메인을 검증하도록 보완했다.
- 초기 전체 생성 SQL에 빠져 있던 커뮤니티 시퀀스 4개를 추가했다.
- 세 언어 메시지 파일의 키 집합을 일치시키고 중복 키를 제거했다.
- 문서의 구현 범위, 테이블·시퀀스 수, 계정·관리자·커뮤니티 현황을 현재 코드에 맞췄다.

## 현재 확인된 구현 범위

- 행정 절차 19개, 일본어·한국어·영어 번역
- 절차 검색, 상황·단계 필터, 상세 서류·단계·창구·공식 출처
- 회원가입 이메일 인증, 로그인 ID 찾기, 비밀번호 재설정, 계정 정보·비밀번호 변경
- 개인 준비 목록, 서류 체크리스트, 일정 달력
- 관리자 회원·절차·서류·단계·출처·창구·공개 상태·커뮤니티 관리
- 커뮤니티 목록·검색·분류·페이지 나누기, 글·이미지·댓글·좋아요·조회수·신고·작성자 삭제

## 공식 유사 서비스와 비교한 부족 기능

비교 대상은 미나토구 생활 안내, 미나토구 외국인 상담, 출입국재류관리청 외국인 생활지원 포털, 도쿄도 외국인 주민 안내이다.

### 우선순위 높음

1. **긴급·재난·의료 안내**
   - 공식 서비스는 재난, 긴급 상황, 질병·부상, 의료기관 정보를 독립된 주요 영역으로 제공한다.
   - 현재 프로젝트에는 긴급 연락처, 대피소, 의료기관 탐색, 재난 공지 영역이 없다.
2. **상담 연결**
   - 미나토구는 전화·방문 외국인 상담과 언어별 상담 일정을 제공하고, 도쿄도와 출입국 기관의 상담 창구도 연결한다.
   - 현재 프로젝트에는 상담 유형, 지원 언어, 운영 시간, 전화 연결을 모은 상담 디렉터리가 없다.
3. **행정 콘텐츠 범위 확대**
   - 공식 포털은 이사뿐 아니라 체류, 노동, 출산·육아, 교육, 의료, 연금·복지, 세금, 주거, 재난 등으로 분류한다.
   - 현재 프로젝트의 행정 절차는 19개이며, 일부 영역은 공식 출처 링크와 기본 안내 중심으로 제공한다.
4. **운영 정책과 개인정보 문서**
   - 회원·이메일·일정·커뮤니티 데이터를 저장하지만 이용약관, 개인정보 처리 안내, 커뮤니티 운영 규칙, 문의 경로 화면이 없다.
5. **커뮤니티 운영 안전장치**
   - 신고와 관리자 숨김 처리는 있으나 게시글 수정 화면, 사용자 차단, 스팸·요청 횟수 제한, 제재 이력, 관리자 처리 메모와 감사 이력은 없다.

### 우선순위 중간

1. **접근성 보조 기능**
   - 미나토구 쉬운 일본어 사이트는 쉬운 일본어, 후리가나, 읽어주기, 글자 크기와 색상 변경 기능을 제공한다.
   - 현재 프로젝트에는 반응형 화면과 기본 HTML 접근성 속성은 있으나 위 보조 기능은 없다.
2. **창구 이용 지원 강화**
   - 현재는 창구 이름과 일부 안내를 보여 주지만 지도, 교통 경로, 운영 시간, 휴무일, 예약 여부를 구조화해 제공하지 않는다.
3. **개인화 알림**
   - 일정 저장은 가능하지만 마감일·예약일 이메일 알림이나 브라우저 알림은 없다.
4. **콘텐츠 최신성 관리**
   - 확인일과 개정 번호는 있으나 오래된 출처를 자동으로 표시하거나 관리자에게 재검토를 요청하는 기능은 없다.
5. **커뮤니티 편의 기능**
   - 인기 글, 저장·북마크, 내 글·내 댓글 모아보기, 새 댓글 알림, 정렬 선택은 없다.

### 현재 범위에서 유지해도 되는 선택

- 지원 언어는 일본어·한국어·영어 세 가지로 일관되게 구현되어 있다. 언어 수를 즉시 늘리기보다 쉬운 일본어와 접근성 보완을 먼저 하는 편이 현재 미나토구 대상 범위에 직접적이다.
- 행정 신청을 서비스 내부에서 대신 접수하지 않고 공식 출처로 연결하는 구조는 현재 문서에 명시된 안내 서비스 범위와 일치한다.

## 후속 구현 확인

이 감사 문서 작성 이후 개인 프로젝트에 필요한 최소 범위로 다음 공개 안내 페이지를 추가했다.

- `/privacy` 개인정보 안내
- `/terms` 이용약관
- `/community/rules` 커뮤니티 운영 규칙

세 페이지는 footer에서 연결되고 비로그인 접근이 허용된다. H2 미리보기 WAR에서 세 경로의 HTTP 200 응답을 확인했다. Oracle SQL은 실행하지 않았다.
