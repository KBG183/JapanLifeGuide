# 설계와 구현 단계

## 목표

미나토구에 거주하거나 이사하는 외국인 취업자가 공식 행정 정보를 읽고,
향후 개인별 준비 상황을 관리하는 일본어 서비스입니다. IT 개발자는 주요 사용자로
설정하되 직종에 따른 행정 자격을 임의로 판단하지 않습니다.

초기 지원 지역은 미나토구이며, 데이터 구조에서는 도쿄도와 구를 분리합니다.
미나토구 선정은 정보통신업 집적에 근거합니다. 외국인 IT 개발자 수 1위라는
통계는 확보하지 못했으므로 그런 문구를 제품·발표에 사용하지 않습니다.

## 1단계 구현 범위

| 경로 | 구현 |
|---|---|
| `/` | 절차 목록으로 이동 |
| `/procedures` | 공개 절차 목록, 상황·단계·빠른 분류 필터, 페이징 |
| `/procedures/{id}` | 대상·기한·서류·단계·창구·출처 |
| `/error` | 일본어·한국어·영어 오류 안내 |

초기 콘텐츠는 해외에서의 전입과 일본 내 다른 지자체에서의 전입입니다.
일반적인 본인 신고를 중심으로 안내하고, 대리 신고 등 예외는 공식 안내로 연결합니다.
기관 개별 주소가 검증되지 않은 항목은 NULL로 두고 공식 창구 안내로 연결합니다.

목록 → Controller → Service → Mapper 인터페이스 → SQL XML → DB → JSP 순서입니다.
검색값은 바인딩하며 SQL 문자열에 붙이지 않습니다. JSP는 사용자 입력과 DB 문자열을
이스케이프합니다. 공개 여부를 목록뿐 아니라 상세 조회에서도 확인합니다.

## 2단계: 회원·개인 관리 — 현재 구현

- Spring Security 세션 로그인, BCrypt 비밀번호 해시, 로그아웃, CSRF 보호
- 비회원은 안내 조회, 회원은 자신의 할 일 관리
- 저장 시 서류 목록·제목·개정 번호를 개인 기록으로 복사
- 회원+절차 유일 제약으로 중복 저장 방지
- 상태: NOT_STARTED(未着手), PREPARING(準備中), COMPLETED(完了)
- 개인 체크 항목은 저장 시점의 사본이며 회원 소유권 조건을 포함해 조회·수정
- 월간 달력과 절차별 일정 추가·완료 전환·삭제
- 원본 개정 번호가 달라지면 최신 안내 확인 메시지 표시

아직 구현하지 않은 2단계 항목은 체크 전체 완료와 실제 행정 처리 완료의 별도 처리,
회원 탈퇴입니다. 비밀번호 변경과 저장한 절차 삭제는 구현되어 있습니다.
- 목록에서 제거할 때 체크 항목과 상위 기록을 하나의 트랜잭션으로 처리

본인 데이터 조회·수정에는 반드시 로그인 회원 ID 조건을 함께 사용해야 합니다.
현재 개인 데이터 조회·수정 쿼리는 로그인 회원 ID로 소유권을 검사합니다.

## 3단계: 관리자 — 현재 구현

- 절차·서류·단계·출처·기관 등록과 수정
- 원본 수정 시 개정 번호 증가, 공개·비공개 관리
- 공개 절차만 새로 저장 가능; 비공개 후 기존 개인 기록은 유지하고 안내
- 외부 URL은 HTTPS 공식 기관 도메인으로 검증한 뒤 저장
- 관리자 작업에 서버 측 권한 검사와 입력 검증 적용

현재 관리자 화면은 회원 권한·상태, 절차 공개 상태, 행정 콘텐츠 목록,
커뮤니티 게시글 상태와 신고 상태를 관리합니다. 행정 콘텐츠의 다국어 번역을 직접
편집하는 화면과 관리자 작업 이력은 아직 구현하지 않았습니다.

## 커뮤니티 — 현재 구현

- 게시판 분류, 검색, 페이지 나누기, 게시글·댓글·이미지
- 좋아요, 조회수, 게시글·댓글 신고와 관리자 처리
- 게시글·댓글 문자열 HTML 이스케이프, 이미지 형식·크기·개수 검증
- 게시글 수정 화면과 이용 규칙 동의·운영 이력은 아직 구현하지 않음. 이용 규칙 안내 페이지는 제공함.

## 서비스 안내 정책 페이지

- `/privacy` 개인정보 안내
- `/terms` 이용약관
- `/community/rules` 커뮤니티 운영 규칙
- 개인 프로젝트 범위의 간단한 정적 안내이며, 회원 탈퇴와 운영 이력은 별도 기능으로 구현하지 않음

## 후속 기능

기관별 주소 조사와 지도, 다른 구 데이터, 알림은 후속 범위입니다.
재류카드·여권 이미지, 카드 번호, 카드 PIN은 수집하지 않습니다.

## 실행 구분

- preview: H2 임시 DB, 공식 기반 초기 데이터, 눈에 보이는 미리보기 표시
- oracle: 사용자가 실행한 SQL로 만든 Oracle 테이블 조회, 자동 초기화 없음
- local: 사용자 PC 접속 설정만 추가, Git 제외

미리보기 성공과 Oracle 연결 성공은 별개로 보고합니다.
