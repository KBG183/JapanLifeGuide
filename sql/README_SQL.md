# Oracle SQL 파일 사용법

이 폴더의 파일은 Oracle SQL Developer에서 열어 복사·수정·실행할 수 있는 일반 SQL 파일입니다.
대상 문법은 현재 확인된 Oracle 11g XE입니다.

## 처음 DB를 만들 때

프로젝트용 일반 Oracle 계정으로 접속한 뒤 다음 중 한 방법을 사용합니다.

### 방법 A: 한 파일씩 실행

아래 순서로 파일을 열고 각각 `F5(스크립트 실행)`를 누릅니다.

1. `00_check_environment.sql` — 현재 계정·Oracle 버전·기존 객체 확인
2. `01_create_tables.sql` — 테이블 25개, 인덱스, 시퀀스 17개 생성
3. `02_sample_data.sql` — 기본 전입 안내 데이터 입력
4. `04_seed_translation_data.sql` — 기본 안내 번역 입력
5. `07_update_document_guidance.sql` — 서류 설명·준비 방법 입력
6. `08_add_resident_procedures.sql` — 생활행정 절차 6개 입력
7. `16_preview_life_procedures.sql` — H2 미리보기용 확장 절차 9~19 입력
7. `09_review_resident_procedure_documents.sql` — 추가 절차의 서류·번역 보완
8. `03_verify.sql` — 생성 결과 확인

### 기존 설치 DB에 이메일 인증 기능을 추가하는 경우

기존 `JL_MEMBER`와 데이터를 유지한 상태에서 다음 파일을 1회 실행합니다.

9. `10_add_email_verification.sql` — 회원 이메일 컬럼, 이메일 중복 제약,
   인증번호 해시·만료시각 저장 테이블과 시퀀스 추가

10. `11_add_password_reset.sql` — 비밀번호 변경·계정 복구 인증번호 저장
    테이블과 시퀀스 추가

11. `12_add_member_status.sql` — 관리자 회원 비활성화를 위한
    `JL_MEMBER.STATUS` 컬럼과 상태 제약조건 추가

12. `13_create_community.sql` — 커뮤니티 게시글·댓글·좋아요·신고·이미지
    테이블과 시퀀스 추가

13. `14_add_community_image.sql` — 13번의 초기 버전에 이미지 구조가 없었던
    설치 환경만을 위한 보완 스크립트

14. `15_seed_community_samples.sql` — 선택 사항인 커뮤니티 샘플 게시글 입력

15. `16_add_community_view_count.sql` — 커뮤니티 조회수 컬럼 추가

이 파일은 이미 존재하는 컬럼·제약조건·테이블·시퀀스를 확인한 뒤 없는 객체만
추가하도록 작성되어 있습니다. 그래도 실행 전 `JL_MEMBER`의 현재 구조를 확인하고,
`ORA-` 오류가 발생하면 같은 파일을 반복 실행하지 말고 오류와 객체 상태를 먼저
확인해야 합니다. 이 파일은 기존 회원의 이메일을 임의로 채우지 않습니다.

### 방법 B: 한 번에 실행

`install_all.sql`을 열고 `F5(스크립트 실행)`를 누릅니다.
이 파일은 같은 폴더의 신규 설치용 SQL을 위 순서대로 실행합니다.
SQL Developer에서 파일 일부만 선택해 실행하지 말고 스크립트 전체를 실행하세요.

## 나중에 내용을 추가하거나 수정할 때

`04_edit_examples.sql`에 다음 예제가 주석 상태로 저장되어 있습니다.

- 현재 지역·분류·절차 조회
- 새 절차 추가
- 기존 절차 수정과 개정 번호 증가
- 화면 공개·비공개 전환
- 준비 서류, 진행 단계, 공식 출처 추가
- COMMIT 전 확인과 ROLLBACK

원하는 예제를 복사하고 ID와 내용을 수정한 뒤 실행하세요. 원본 예제는 보관해 두는 편이 안전합니다.

## 포함하지 않은 명령

- Oracle 계정 생성·비밀번호 설정: 실제 계정명, 권한, 테이블스페이스를 알 수 없어 임의로 만들지 않았습니다.
- 전체 테이블 삭제·초기화: 기존 데이터 삭제 위험 때문에 제공된 설치 파일에서 자동 실행하지 않습니다.
- 가상의 회원 데이터: 운영용 초기 회원을 임의로 만들지 않기 위해 넣지 않았습니다.

## 실행할 때 지켜야 할 점

- `SYS` 또는 `SYSTEM`이 아닌 프로젝트용 일반 계정에서 실행합니다.
- 파일 인코딩은 UTF-8로 유지합니다.
- `01_create_tables.sql`과 `02_sample_data.sql`은 최초 한 번만 실행합니다.
- `ORA-`로 시작하는 오류가 나오면 같은 파일을 반복 실행하지 말고 오류 문구와 현재 객체 상태를 먼저 확인합니다.
- Oracle DDL은 자동 COMMIT됩니다. 테이블 생성 명령은 `ROLLBACK`으로 취소되지 않습니다.
- 일본어·한국어 문자열은 `N'문자열'`로 작성합니다.
- 실행 계정과 애플리케이션의 DB 접속 계정은 같아야 합니다.
